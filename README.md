## Общая информация.
 
Эта программа предназначена для параллельного повышения резкости нескольких изображений
с использованием матрицы по пяти отсчетам:  
|0  -1  0 |  
|-1  5  -1|  
|0  -1  0 |  
Для повышения резкоcти используются: 
* библиотека scipy
* ручная обработка разбиением изображения на матрицы и последующей сверткой с помощью 
библиотеки numpy
### Уточнение.
При использовании таких платформ как thecatapi.com и thedogapi.com нужно использовать впн,  
так как их ip-адреса базируются на сервисе cloudflare, который был заблокирован на территории РФ  

Но действительно это требуется только при запуске всей программы как единого модуля, если использовать  
отдельно ImageProcessor, то использовать можно любой источник изображений.
